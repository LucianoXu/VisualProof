# Reading declarations

Search, a declaration's record, source, context, module, and what Lean says; any level.
`declaration?include=source,context,uses,users,describe,print` gets all six parts in one request.
`uses`, `users`: [Targets and their TCB](tcb.md); terms: [Words](words.md). MCP: `search`;
`declaration` (`names` for several); `source` (actions `source`, `context`, `module`); `lean`
(actions `describe`, `print`).

## `GET /api/agent/search?q=&limit=`

`q`: at least 2 characters, every word found in the name, statement or docstring; ranked name,
statement, then docstring matches. `limit` 1–200, default 20. Folded names match too (`via`: the one
matched).

```json
{"query": "IsRegularPrime", "counts": {"name": 4, "statement": 8, "doc": 0}, "more": 6,
 "hits": [{"name": "flt_regular", "kind": "theorem", …, "where": "statement", "snippet": "∀ {p : ℕ} …, IsRegularPrime p → …"}, …]}
```

## `GET /api/agent/declaration?name=&include=`

Everything about one declaration; here `include=print` while Lean loads:

```json
{"name": "IsRegularNumber", "kind": "def", "module": "…", "external": false, "file": "…", "range": {"line": 27, "col": 0, "endLine": 29, "endCol": 68},
 "statement": "ℕ → Prop", "doc": "…", "also": [], "flags": [], "axioms": […], "nonStandardAxioms": [], "hash": "…", "kernel": "…",
 "editedSinceCompiled": false, "review": {"status": "approved", "trusted": false, "trustedBy": [], "needsReview": true, "advice": [],
   "opinions": [{"by": "Alice", "agent": false, "verdict": "approve", "at": "…", "onPresentVersion": true}], "youAdvised": false},
 "isTarget": false, "keyFor": [], "inTcbOf": ["flt_regular"], "tcbSize": {"project": 0, "external": 10}, "usesDirect": 17,
 "usedBy": {"direct": 5, "all": 19}, "print": {"status": 503, "error": "…", "retryAfter": 5}, "failed": {"print": 503}}
```

- `statement`: the type, fully qualified; `range`: 1-based lines; `leanName`, `display`, `grammar`,
  `interprets`, `interpretedBy`: notation units only; `also`: generated from its command, folded
  in, covered by `axioms` and `hash`.
- `axioms`: all its proof and definition reach; `nonStandardAxioms`: beyond the standard three
  (`sorryAx`). `review`: `opinions` (people's latest) and `advice` (agents', `yours: true`), one
  each; `onPresentVersion: false`: on an earlier version; `verified: true`: from someone invited by
  a personal link, `by` their name now; `trustedBy`: covering prefixes, or `["standard axiom"]`.
- `editedSinceCompiled`: file differs from what was compiled (null outside the project); `keyFor`,
  `inTcbOf`: targets it is key for, whose TCB holds it; `usesDirect`, `usedBy.direct`: what it
  refers to by name, what refers to it (`uses`, `users` list them); `usedBy.all`: all reaching it,
  proofs included.

**`include`**: comma-separated parts, each answered under its name as its endpoint would. `uses`,
`users` take `offset`, `limit`, `where` from the query; `print` takes `proofs`; `describe` and
`print` share `wait` (ms, default 20000, max 60000). A failed part carries its error and `status`
and is listed in `failed` (ask again); the others still answer.

## `GET /api/agent/declarations?names=&include=`

Also `declaration?names=` (same answer). Up to 25, comma-separated (a comma inside `«…»` belongs to
the name; repeats answered once), each as by `declaration`, same `include`; `wait` covers the whole
request, so a slow Lean answer leaves less for the next. Answer `{count, found, declarations}`; a
name not in the graph is answered in place:
`{"name": "systemOfUnits.indx", "status": 404, "error": …, "didYouMean": […]}`.

## `GET /api/agent/source?name=&snapshot=`

As the source window shows it: docstring, attributes and proof included.

```json
{"name": "IsRegularPrime", …, "compiled": true, "context": "section\nnoncomputable section\nopen Nat\n…",
 "text": "/-- The definition of regular primes. -/\ndef IsRegularPrime …"}
```

- `context`: what is in force there, as Lean, one command per line ("" if nothing): `GET context`'s
  list plus `noncomputable section`, macros and `… in` commands right before it; elaborated (opens
  resolved, a `variable` per binder) or read from the text, per its `precision`.
- Advice records `context`, a blank line, `text` (just `text` if `context` is ""), as people's do.
- `compiled: false` (with `note`): file changed since compiled; the present text, found by name;
  advice waits for the next build. Outside the project: 404 (use `describe`, `print`).
- A unit (`also`, `alsoNote`): what the same command generated, listed with it (`print` each);
  advice on the unit covers them, its hash changes with them. `generatedNote`: generated by a
  command none of whose declarations could fold it in; its source is the command's text.

**At a past build** (`snapshot=<id>`, [History](history.md)): the text it compiled, at its recorded
place (`line`, `endLine`), found by the name then, the name now via renames (`asked`: yours), or as
generated by its command; plus `snapshot` (`{id, at, commit}`), `check`, `note`; `context` from
that text (`GET context`: latest build only). `check`: `lake` (Lake hash matches) or `places` (no
hash kept, a build from before texts were kept: the one candidate agreeing with every recorded
place: imports, declaration bounds, doc comments, names). Text not kept (edited after the build and
not in the commit, or no match): 404, `kept: false`, why in `error`, statement and doc then; never
another text. Not reviewed: advice is on the latest build.

## `GET /api/agent/context?name=`

What is in force where it is written, taken apart, outermost first, each with the 1-based `line` of
its command (what a section held ends with it): namespaces and sections; `open`s (`open … in` right
before it: `in: true`; `open scoped`: `scoped`); `variable`s, binders as written; `universe`s;
`set_option`s; commands holding to their section's end (`local`/`scoped` notation, instances,
attributes, `include`, `omit`). `precision`:

- `elaborated` (`exact: true`): the elaborator's scope before the command, as the usage pass read it
  (file unchanged since): `open`s resolved (`open X` in `namespace A` is `open A.X` if that is a
  namespace), one entry per `variable` binder with the names it `binds`, **`used: true` on variables
  Lean included in this declaration**, `options` differing from Lake's for the module.
- `text`: read up to the declaration's text (docstring, attributes), unelaborated (pass not run yet
  or failed on the module, or file changed): `open`s and `variable` lines as written (comments out,
  lines joined); included variables unknown.

```json
{"name": "FltRegular.CaseI.f0k₁", …, "line": 36, "imports": […], "precision": "elaborated", "exact": true, "namespace": "FltRegular.CaseI", "namespaces": ["FltRegular.CaseI", "FltRegular"],
 "blocks": [{"kind": "namespace", "line": 12, "name": "FltRegular"}, …], "opens": [{"line": 8, "namespaces": ["Finset"], "text": …}],
 "variables": [{"binds": ["p"], "line": 14, "text": "{p : ℕ}"}, …], "local": [{"line": 16, "text": "local notation …"}], "universes": [], "options": []}
```

- `opens[].namespaces`: graph namespaces it brings in (in `namespace A`, `open X` may mean `A.X`);
  empty if none of the graph's names are under it. `blocks[].kind`: `namespace`, `section` (`name`
  null if anonymous), `mutual`. `compiled: false` (with `note`): read from the present text, up to
  where the name is found now.
- Not listed: notation and instances from other files (an `open` brings what its namespace scopes);
  `print` shows what Lean elaborated, names in full.

## `GET /api/agent/module?name=` or `?of=<declaration>`

A project module (or a declaration's): doc comments (`/-! … -/`) with their lines, imports,
importers, declarations in file order (variants, weaker or stronger forms no TCB reaches). Doc
comments up to 60,000 characters (`docsCut` if more). A file changed since compiled is read as it
is now (`note`).

```json
{"name": "FltRegular.NumberTheory.RegularPrimes", …, "imports": [], "importedBy": ["FltRegular", …],
 "docs": [{"line": 7, "endLine": 15, "text": "# Regular primes…"}], "count": 8, "declarations": [{"name": …, "kind": "def", "line": 27}, …]}
```

## `GET /api/agent/describe?name=&module=&wait=`

Lean's hover: the signature with every implicit argument and instance, and the doc (`#check` in a
scratch file importing the module). For abbreviated statements, external names (`ClassGroup`),
folded names. `wait`: ms, default 20000, max 60000.

Any Lean name (a constructor, a field, macro output). Module imported (`moduleChosen`: which and
why): `module` if given (a module of the graph; an outside declaration is asked about in a project
module importing it); else the declaration's own; else, for a name the graph lacks, the nearest
declaration's it is under (`systemOfUnits.units`: `systemOfUnits`'s); else the root module.

```json
{"name": "systemOfUnits.units", "module": "…", "moduleChosen": "that of systemOfUnits, the declaration it is under",
 "inGraph": false, "lean": "```lean\nsystemOfUnits.units … : Fin s → G\n```\n***\nThe family of units …"}
```

| status | when |
|---|---|
| 503 | Lean loading the module's imports (a minute, the first time): `Retry-After: 5`, `pending`; ask again. Or no Lean here (a saved graph) |
| 502 | Lean failed or could not answer (the hint: what to use instead) |
| 404 | unknown to Lean there: `lean` (what it said), `didYouMean` (graph names, the enclosing declaration first; `print` it for its fields and constructor) |
| 400 | `name` or `module` not a Lean name (only full dotted names reach the scratch file), or `module` not in the graph |

## `GET /api/agent/print?name=&module=&proofs=&wait=`

`#print`: the declaration as Lean elaborated it, value and names in full: macro output (what a
project's own command writes from one block), auto-bound implicits, a Prop-valued definition's
proposition, a structure's fields and constructor, recorded attributes (`@[reducible]`). Any Lean
name; module and `wait` as for `describe`. Proofs show as `⋯` (a TCB never looks inside one);
`proofs=1` prints them. At most 50,000 characters, cut at a line's end, with
`truncated: {shown, length}`.

```json
{"name": "IsRegularPrime", …, "moduleChosen": "its own", "inGraph": true, "proofs": false,
 "lean": "def IsRegularPrime : ℕ → Prop :=\nfun p => IsRegularNumber p"}
```

`warnings` when Lean gave any. `seeAlso`: names generated from the same command that the value
refers to (which `#print` shows only by name), to print in turn. 503 while Lean loads, 404 for an
unknown name (as `describe`), 422 when Lean refused otherwise (`lean`: what it said).
